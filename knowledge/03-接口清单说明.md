# 接口清单说明

后端统一返回结构 `{code, msg, data}`，code=200 成功，其余失败（401 未登录 / 403 无权限 / 404 不存在 / 400 参数错误）。
以下路径均为实际存在的接口（来源 demo/ 控制器代码）。

## 认证

- POST /api/login：body {username, password}；成功返回 token、username、role（ranger 或 admin）、phone、jobNum、id。

## 大屏与态势

- GET /api/forest/bootstrap：一次性返回园区信息、天气、火险分析、分区、传感器、无人机、巡护任务、火情事件、趋势、地图、护林员位置。
- GET /api/forest/sensors/{id}/history?metric=smoke|temperature|humidity&limit=≤300：节点历史（GT-01 烟雾为真机采样，其余为平台仿真趋势）。
- GET /api/forest/map、PUT /api/forest/map、POST /api/forest/map/view：园区地图边界与视图中心。
- PUT /api/forest/zones/{id}、POST /api/forest/zones、DELETE /api/forest/zones/{id}：分区管理（存在未结案警情的分区禁止删除）。
- POST /api/forest/rangers/position：护林员位置上报。

## 火情事件

- POST /api/forest/incidents：创建警情（走多源融合模型定级）。
- POST /api/forest/incidents/simulate：课程演示模拟一/二/三级警情。
- PUT /api/forest/incidents/{id}：更新处置状态 status/result/ranger（仅护林员在页面人工操作；AI 助手无权调用）。

## 无人机巡护

- POST /api/forest/missions：创建任务（可关联警情 incidentId）。
- PUT /api/forest/missions/{id}/status：接取（已接收）与前往现场。
- POST /api/forest/missions/{id}/start：开始手动巡护。
- POST /api/forest/missions/{id}/telemetry：保存飞行遥测。
- POST /api/forest/missions/{id}/complete：返航归档并生成总结（模型可用则 AI 总结，否则规则总结）。
- GET /api/forest/missions/{id}/detail：任务详情+照片+最近遥测。
- POST /api/forest/missions/{id}/photos：上报现场照片。

## 广播与设备

- POST /api/forest/broadcast、GET /api/forest/broadcast/latest、GET /api/forest/broadcast/history?limit=≤30。
- GET /api/forest/equipment/bootstrap：设备、故障、维护历史、自检汇总。
- POST /api/forest/equipment：登记设备（传感节点/无人机坐标必须在园区边界内）。
- PUT /api/forest/equipment/{id}/status、PUT /api/forest/equipment/faults/{id}、POST /api/forest/equipment/maintenance。
- POST /api/forest/equipment/{id}/self-test、GET /api/forest/equipment/self-tests/{testNo}：设备自检。

## 摄像头 AI 复核

- POST /api/review/upload：上传 base64 帧 + 浓度，调用本地 YOLO 服务做视觉融合判定。
- GET /api/review/latest：最近一次复核结果（verdict：fire/smoke/steam/normal）。

## AI 助手（本地）

- GET /api/forest/ai/health：AI/Ollama/模型/Qdrant 状态。
- POST /api/forest/ai/chat：{conversationId?, message} → answer/sources/suggestedActions/model/latencyMs。
- GET /api/forest/ai/conversations、GET/DELETE /api/forest/ai/conversations/{id}：仅本人会话（管理员可见全部会话元数据，删除仍仅限本人）。
- GET /api/forest/ai/knowledge/documents：知识文档状态列表。
- POST /api/forest/ai/knowledge/reindex、POST /api/forest/ai/knowledge/documents（multipart）：仅 admin。
