# 森林防火知识库目录

本目录是本地 AI 助手（RAG）的知识来源。系统启动后可通过“重建知识库”按钮（仅管理员）
或由 `ollama` + `qdrant` 首次就绪后自动/手动触发索引。

## 允许索引的文件类型

- `.md`、`.txt`、无扩展名的 README 类说明文件
- 管理员通过 AI 助手页面“导入文档”上传的 `.md`、`.txt`、`.pdf`（保存在独立上传目录，不在本仓库中）

## 永远不会被索引的内容

- `.env`、`application-prod.yml`、任何包含密码、Token、API Key 的文件
- `node_modules`、`target`、`dist`、`.git`、日志文件、二进制文件
- 本目录之外的任意路径（检索与导入都有路径穿越防护）

## 内容纪律

1. 本目录文档只记录**本系统真实存在**的模块、接口、字段与算法（来源为代码与 README）。
2. 缺少正式消防预案等权威文件时，只保留模板并标注“需要管理员补充正式内容”，禁止编造规范条款。
3. AI 助手回答会把“知识库事实”“实时数据库事实”“模型推断”分开表述。
