# 系统与模块总览

## 项目定位

森林景区火灾预警处置系统（福州国家森林公园古树防火巡护平台），提供游客预警大屏、
护林员桌面端/移动端、森林传感器监测、无人机巡护、设备运维、摄像头 AI 复核，
以及基于本地 Ollama 小模型与 Qdrant 向量库的森林安全智能助手。

## 技术栈

- 前端：Vue 3 + Vite + Vue Router + Element Plus + Axios + ECharts + 高德地图 JS API，Nginx 静态托管并将 `/api` 反代到后端。
- 后端：Java 8 + Spring Boot 2.7.15 + MyBatis-Plus + MySQL 8 + RestTemplate + Fastjson2；华为云 IoTDA SDK 可选接入真机烟感。
- AI：Ollama（qwen3:4b 对话、qwen3-embedding:0.6b 嵌入）+ Qdrant 向量库，全部本地运行，无云端大模型、无真实 API Key。
- 部署：Docker Compose（mysql、backend、frontend、ollama、ollama-init、qdrant）。

## 主要页面

- `/visitor-alert` 游客火险预警大屏（无需登录）
- `/login` 护林员登录
- `/ranger` 护林员桌面工作台（防火态势、古树监测、历史趋势、火情事件、无人机巡护、广播与疏散、设备运行保障）
- `/mobile` 护林员移动巡护端
- `/ranger/equipment` 设备运维
- `/ranger/ai` 森林安全智能助手（对话、知识库管理）

## 角色与账号（课程演示级）

- `ranger/ranger123`：护林员，使用全部巡护与处置功能。
- `admin/admin123`：管理员，在护林员功能之上可维护 AI 知识库（导入文档、重建索引）。
- 登录返回 mock token（`mock-token-用户名`），仅用于演示；系统未实现 JWT 与密码哈希，公网部署前必须补齐。

## 数据初始化

数据库 `smoke_db` 由 `demo/src/main/resources/forest-schema.sql` 与 `forest-ai-schema.sql`
在服务启动时以 `CREATE TABLE IF NOT EXISTS` 幂等方式建表并写入演示种子数据。
MySQL 数据保存在 Docker 卷 `forest_mysql_data`，重建容器不会丢数据。
