EDGE · CLOUD · HEALTH

把安全判断，
放在离危险最近的地方。

系统采用 BearPi 边缘端与 Spring Boot 云端协同架构。边缘端承担快速烟雾判断与本地强制报警，云端负责时间序列分析、动态误报抑制、设备健康监测、用户权限和远程控制。即使网络异常，真实危险状态依旧能够在设备端独立触发报警。

01 · EDGE DECISION

端侧快速判断

以动态背景基线为参照，根据烟雾倍率和硬阈值执行 NORMAL、PREWARNING、ALARM 三态判断。真实 ALARM 拥有最高执行优先级。

02 · FALSE ALARM SUPPRESSION

动态误报抑制

云端使用稳定背景基线、短窗口连续异常次数和恢复条件进行二次判断，避免单点抖动直接升级为烟雾报警。

03 · DEVICE HEALTH

设备健康监测

持续区分 NORMAL、STALE、OFFLINE 与 SENSOR_FAULT。系统不仅判断环境是否安全，也判断“当前读数是否值得信任”。

04 · SAFETY PRIORITY

安全优先控制

管理员可以远程控制 LED 与蜂鸣器，但真实烟雾报警状态会强制接管执行器，防止手动关闭覆盖安全底线。

05 · DATA SCOPE

房间级数据隔离

居民只能查看本人或本人房间绑定设备的监测数据与告警；管理员拥有全局管理权限，权限校验在后端执行。

06 · CLOUD CONTROL

端云闭环

设备上行属性进入云端与数据库，管理员下行命令经 IoTDA 到达 BearPi，实现采集、传输、处理、控制的完整闭环。
