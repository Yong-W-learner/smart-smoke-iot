演示工具

仅对 DEMO 模拟节点生效（演示数据）；真实硬件节点不会被注入任何模拟数据。选择模拟节点并触发可控场景，数据将逐步进入判定与事件链路。
演示数据
NORMAL正常环境，浓度在小幅波动，所有指标正常。
SHORT_SPIKE短时尖峰：快速升高后回落，自动回到 NORMAL。
RISING持续上升：逐步触发预警→报警链路。
WARNING预警：浓度持续升高但尚未报警。
ALARM持续高浓度报警，进入火险事件队列。
RECOVERY从高浓度逐步恢复，观察事件自动闭环。
OFFLINE设备离线，停止上报并标记为离线。
STALE数据过期：停止上报并标记为 STALE（区别于离线）。
SENSOR_FAULT传感器数据异常，触发传感器故障健康状态。
森林火险事件处置闭环 · 演示步骤
1选择 DEMO 节点（如 FS-N-002）并触发 RISING / ALARM，地图节点变红、事件进入队列顶部。
2在事件详情点 确认告警 → 派发无人机（记录 DRONE_DISPATCHED）。
3无人机任务点 推进状态 到现场，再 确认火点 → 事件 drone_confirmed=1、优先级强制 ≥95（RED）。
4触发 RECOVERY，烟雾恢复后系统自动写入环境恢复时间（不依赖人工确认）。
5填写处置结果、点 关闭事件；若事件点 1km 内有古树/栖息地，需先完成生态回访才允许关闭。
6整条链（发现→确认→派发无人机→确认火点→恢复→回访→关闭）在事件详情时间线中完整保留。
